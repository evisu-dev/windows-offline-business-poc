# システム概要

## プロジェクト名

Offline Work Order Manager PoC

## 目的

Windowsインストール型・オフライン業務アプリケーションの技術的成立を検証するPoC（Proof of Concept）。

## コンセプト

- インターネット接続不要で動作するデスクトップ業務アプリ
- PHP/Laravel + NativePHP によるクロスプラットフォーム開発
- SQLiteによるローカルデータ永続化
- Windowsへのインストーラー配布を最終目標とする

## 技術スタック

| 項目 | 技術 | バージョン |
|---|---|---|
| フレームワーク | Laravel | 12.x |
| ランタイム | PHP | 8.4.x |
| デスクトップ化 | NativePHP Desktop | 2.2.1 |
| JavaScript実行環境 | Node.js | 22.x |
| データベース | SQLite | - |
| PDF生成 | barryvdh/laravel-dompdf | ^3.1 |
| ビュー | Blade + 素のCSS | - |
| パッケージ管理 | Composer | 2.x |

## 制約・前提

- 外部APIやCDNへの依存なし（完全オフライン動作）
- 認証機能なし（単一ユーザー利用を前提）
- Tailwind CSS / Alpine.js は未導入（素のCSSで実装）
- Windows向け配布物はWindows環境でのみ生成可能
