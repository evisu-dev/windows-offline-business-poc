## Step 1: Node.js確認

```powershell

# v22.x.x であること
# v10.24.1 の場合は以下でLTSを再インストール
# winget install OpenJS.NodeJS.LTS
```

PATHにv22が含まれていない場合:

```powershell
# Phase1ビルド時に使っていたNode.js v22.16.0を探す
Get-ChildItem -Path "C:\" -Filter "node.exe" -Recurse -ErrorAction SilentlyContinue -Depth 5 | ForEach-Object { "$(& $_.FullName --version) : $($_.FullName)" }

# 見つかったら現在セッションのPATH先頭に追加
$env:PATH = "C:\見つかったディレクトリ;$env:PATH"
```
